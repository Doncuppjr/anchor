# ANCHOR browser installer

The installer is a static ESP Web Tools site, generated by
`generate-site.py` from CI-generated C5 production and debug firmware.
It is meant for initial **USB flashing**, not in-flight updates.

Each manifest selects chipFamily `ESP32-C5` and writes the full 8 MB
image at offset 0x0. The installer explicitly asks about erasing settings.
GitHub Actions builds and validates the same image for regular firmware
artifacts; no extra firmware version is hidden in the web page.

Open the HTTPS site in a desktop Chromium browser that supports Web Serial,
connect a USB data cable, and choose Production or Debug. If normal connection
fails, enter the Espressif ROM loader via BOOT/RESET and retry.

GitHub Pages must use **GitHub Actions** as its source. The workflow also
uploads a downloadable static site artifact so the generated manifests and
firmware can be inspected even if Pages is not enabled yet.

This does not replace the radio's Wi-Fi OTA path (which accepts only
application-only images), and it does not add UF2 support to the C5.

Once GitHub Pages is enabled in repository settings, push a change under
`ANCHOR/installer/` or manually dispatch the ANCHOR workflow to publish the site.
