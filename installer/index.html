Anchor Firmware Installer

USB firmware provisioning for supported Anchor Bluetooth bridge boards

Bench firmware, not a validated production release. USB installation replaces the full flash and can erase stored pairing/settings. Keep the transmitter and model inactive, and test Trainer and Telemetry before use.

Experimental hardware target. The C3 Super Mini firmware compiles and passes automated image checks, but GPIO wiring, UART, BLE, sleep/wake, and OTA have not been verified on physical C3 hardware. Confirm the board type and pinout before flashing.

Production firmware

BLE Trainer, Telemetry, enable control and Wi-Fi OTA. Diagnostic commands and verbose logging disabled.

Diagnostic firmware

Same features plus USB bench commands and verbose logging. For hardware testing.

First-time installation

  1. Choose the exact board model above. Selecting a different chip family can make the image unusable.
  2. Connect that board over a USB data cable; choose Production or Diagnostic and select its serial port.
  3. If it fails to connect, enter the board's ROM downloader with BOOT/RESET, then retry.
  4. Confirm the flash/erase prompt, and bench-test the full Trainer/Telemetry pipeline after installation.

This site uses ESP Web Tools for full-flash USB installation, not UF2. The separate Wi-Fi OTA page accepts only an *-app.bin file, never the full image.
