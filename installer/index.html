ANCHOR Firmware Installer

RadioMaster TX15 Bluetooth bridge · Seeed XIAO ESP32-C5

Bench candidate, not a validated production release. Installation writes a full flash image. It may erase existing pairing/settings. Keep the transmitter and model inactive while updating, and verify Trainer and Telemetry on the bench before use.

Production firmware

Normal BLE Trainer and Telemetry, PH11 power control, and Wi-Fi OTA. Bench commands and verbose serial traces are disabled.

A browser with Web Serial support is required. Try a current desktop Chrome or Edge. This installer must be opened over HTTPS.

Diagnostic firmware

Includes the same functional features, plus USB bench commands and diagnostic logging. Intended for testing only.

A browser with Web Serial support is required. Try a current desktop Chrome or Edge. This installer must be opened over HTTPS.

First-time installation

  1. Connect the XIAO ESP32-C5 via a USB-C data cable.
  2. Choose the production option above and select the ESP32-C5 serial port when prompted.
  3. If the board does not connect, hold BOOT, tap RESET, then release BOOT. Retry installation.
  4. Confirm any erase/replace prompts carefully. Wait for the flashing process to finish, then reset the board.
  5. Bench-test the TX15 Trainer/Telemetry connections before operating a model.

This installer performs an initial USB flash using the ESP32-C5 ROM loader, not UF2. Existing ANCHOR devices can use the Wi-Fi OTA page instead: the Wi-Fi updater accepts only the *-app.bin file, never the full image offered by this installer.

Source and build instructions: ANCHOR repository. Browser flashing uses ESP Web Tools. Firmware checksum and build metadata are generated by GitHub Actions.
